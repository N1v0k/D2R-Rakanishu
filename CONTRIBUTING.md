# Contributing

Issues are welcome. Please include the app version, device model, Android version, steps to reproduce, and the expected and actual result. Remove personal information from logs and screenshots. Do not attach game files, import packs, credentials or private saves.

This repository is maintained privately and exported for public use. Changes are reviewed and integrated in the private source tree before export, so pull requests may not be merged directly.

Use English for documentation, commit messages and code comments. Comments should explain information the code cannot express. Keep game content and signing keys outside the repository, retain license notices, and run the relevant existing tests before proposing a change.
